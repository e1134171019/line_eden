# 獎學金來源納入審查規則

新增網站不得直接加入正式監測。每個候選來源必須先完成以下審查，並在 `AdditionalScholarshipSource.review_reason` 留下納入理由。

## 使用者背景基準

來源相關性以目前使用者條件評估：

- 龍華科技大學電子工程系四技進修部在學生
- 戶籍位於新北市新莊區
- 電子、電力電子、逆變器、能源、半導體、資訊與工程研究方向
- 無特殊身分類別；清寒、低收入、原住民、身障等限定方案不可視為一般適用來源

## 必要條件

候選來源必須同時符合：

1. 網址可由 GitHub Actions 安全連線。
2. 解析器能取得具體獎學金公告，而不是只有導覽頁或空頁。
3. 與既有來源相比具有獨特價值，不能只是同一方案的完全重複入口。
4. 來源目標不是僅限其他學校在校生使用的校內獎學金。
5. 必須有明確 `review_reason`，說明相關性、實際產出或獨特覆蓋。

## 優先納入

- 官方主辦單位的工程、電子、能源、半導體或科技獎學金
- 新北市、新莊區及全國性大專獎學金官方入口
- 能穩定產出多個校外方案的公告中心
- 能補足現有來源未涵蓋企業或基金會方案的網站

## 直接排除

- 已由 TUN 指定方案或其他官方來源完整監測的重複入口
- 只服務該校在校生、且沒有校外公開方案的校內平台
- 即時稽核為零筆，且無固定官方方案頁可作安全追蹤
- TLS、DNS、HTTP 或解析結構持續失敗，且沒有足夠獨特價值值得維護專用 collector
- 大量轉載但新增方案幾乎全部被既有來源去重的低增益網站

## 驗證流程

1. 候選網站搜尋與人工審查
2. 增量模式抓取第一頁
3. 完整來源契約測試
4. 計算解析筆數、跨來源去重後新增筆數及失敗狀態
5. 通過品質測試與來源契約後才合併到 `main`

來源數量不是目標；提高符合資格方案的發現率才是目標。
